Сохранённый отчёт утверждённой Django-копии: мобильный 97, LCP 2191 мс, TBT 162 мс; компьютер 100, LCP 591 мс, TBT 0. В Laravel мобильный показатель 95 — целевые 98–99 **не достигнуты**. Прямое сравнение ограничено разными серверными средами: новый замер выполнялся внутри Docker на Windows. Дизайн и JS анимации при PHP-переносе сохранены. Перед публичным переключением нужны повторные измерения на реальном PS.kz, а также проверка настоящего телефона/Safari.

Убраны повторные SQL-запросы к общим контактам, меню и текстам: публичный кеш хранит только массивы, разделён по базе, обновляется после сохранения/удаления и завершения транзакции. Тестируется настоящее чтение файлового кеша. Нельзя кешировать весь HTML с персональными сессиями, nonce и токенами форм.

Runtime-каталог Docker вынесен в отдельный Linux-том: кеши, сессии и компилированные Blade-шаблоны хранятся в Docker на D, не читаются через Windows bind-mount. Медиа и private snapshot монтируются отдельно. Статические ресурсы выдаёт Nginx, включены gzip и долгий кеш для версионированных файлов.
